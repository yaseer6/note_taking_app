# Note Taking App

A simple note-taking application built with Flutter and Dart as my first Flutter project.

This project was created while learning the fundamentals of Flutter and Dart, including widgets, state management, user interaction, and file handling.

## Features

- Create notes
- View notes
- Edit notes
- Delete notes
- Save notes using file read/write operations

## Technologies

- Flutter
- Dart

No external packages are used for storing notes.

## What I Learned

This project was mainly focused on learning the fundamentals of Flutter.

While building it, I learned and applied:

- Stateless Widgets
- Stateful Widgets
- Widget composition
- Managing UI state
- User input and interactions
- Dart file read/write operations
- Basic Flutter application structure

## Project Status

This is an ongoing learning project and is not considered a finished production application.
